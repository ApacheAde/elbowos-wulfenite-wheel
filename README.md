# Wulfenite Wheel

Full-colour Python 3 neon bucket-wheel arcade for [ElbowOS](https://x.com/ElbowOS).

Spin a copper kiln wheel. Scoop lime and gold ore into the buckets. Crimson slag breaks the haul.

This is an original arcade game. It is not a commercial emulator and it does not use trademarked characters.

## Play

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 wulfenite_wheel.py --play
```

A / D or arrows spin the wheel. Space boosts. R restarts.

## Record a 9:16 reel

```bash
python3 wulfenite_wheel.py --record
```

Writes a 1080x1920, 15-second, 30fps H.264 MP4.
